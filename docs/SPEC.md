# XTerminal Pro — 设计文档

创建时间：2026-03-30 | 作者：龙虾003

## 1. 目标

打造一个比 Xterminal 更轻量的 SSH 终端工具，基于 Tauri 构建，内存占用 <100MB，安装包 <10MB。

## 2. 用户

- **主要用户**: 开发者、运维工程师
- **使用场景**: 日常 SSH 连接管理、文件传输、多服务器运维

## 3. 功能清单

### V1 核心功能（按优先级）

| 序号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| 1 | SSH 连接 | P0 | 密码/密钥认证，代理跳板 |
| 2 | 终端模拟器 | P0 | xterm.js，多标签页 |
| 3 | 连接管理 | P0 | 分组/标签，配置持久化 |
| 4 | SFTP 文件管理 | P0 | 双栏，拖拽上传下载 |
| 5 | 多服务器管理 | P0 | 分组管理，快速切换 |
| 6 | 快捷命令 | P1 | 预设命令，一键执行 |
| 7 | 主题系统 | P1 | 暗色/亮色/自定义 |
| 8 | 会话录制 | P1 | 终端操作日志 |
| 9 | 端口转发 | P1 | 本地/远程/动态 |
| 10 | 本地终端 | P2 | 不连服务器也能用 |

### V1.5 增强功能

- AI 对话（自然语言→命令）
- 批量执行（多服务器同时执行）
- 通知告警（命令完成/错误提醒）
- 会话分享（生成只读链接）

## 5. 数据模型

### 连接配置
```rust
struct ConnectionConfig {
    id: String,           // UUID
    name: String,         // 显示名称
    host: String,         // 主机地址
    port: u16,            // 端口（默认22）
    username: String,     // 用户名
    auth_type: AuthType,  // 密码/密钥/证书
    group: String,        // 分组名
    tags: Vec<String>,    // 标签
    jump_host: Option<JumpHost>,  // 代理跳板
    last_connected: DateTime,
}

enum AuthType {
    Password { password: Encrypted<String> },
    Key { path: String, passphrase: Option<Encrypted<String>> },
    Certificate { cert_path: String, key_path: String },
}
```

### 快捷命令
```rust
struct QuickCommand {
    id: String,
    name: String,
    command: String,
    group: String,
    run_on: RunTarget,  // Single / All / Selected
}
```

## 6. 安全

- 密码/密钥使用系统 keyring 存储（Linux: secret-service, macOS: Keychain, Windows: Credential Manager）
- 配置文件使用 AES-256-GCM 加密
- 不在磁盘上明文存储任何凭证

## 7. 性能目标

| 指标 | 目标 |
|------|------|
| 冷启动时间 | < 1s |
| 内存占用（空闲） | < 30MB |
| 内存占用（10会话） | < 100MB |
| 安装包大小 | < 10MB |
| SSH 连接建立 | < 500ms |
